# Graph Traversal using Depth First Search 

## Problem Statement

Develop a simple **N-Queens Puzzle** using an adjacency list representation. The program should:

- Create a graph using an adjacency list.
- Allow the user to define connections between vertices.
- Traverse the graph using DFS with a stack.
- Visit each vertex exactly once.
- Display the order in which the vertices are visited.
