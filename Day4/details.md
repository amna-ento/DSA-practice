# Recruitment Decision Support System

## Problem Statement

Develop a Recruitment Decision Support System using a Decision Tree to automate the candidate screening process. The system should allow recruiters to:

- Enter candidate details through user input.
- Evaluate candidates using a Decision Tree.
- Check eligibility based on predefined recruitment criteria.
- Display the complete decision path followed during evaluation.
- Generate the final hiring decision (HIRE or REJECT).
- Store candidate information using Object-Oriented Programming.
- Dynamically traverse the tree based on candidate attributes.
- Simulate a real-world recruitment screening process.

## DSA Topics Covered

- Binary Tree (Decision Tree)
- Tree Traversal
- Conditional Decision Making
- Object-Oriented Programming (Classes & Objects)
- Functions / Modular Programming
- Dynamic Attribute Access (`getattr()`)
- Boolean Logic & Comparison Operators
- Time Complexity Analysis (Tree Traversal)
