# Hash Tables & Train Reservation System

## Problem Statement

Develop programs to understand and implement **Hash Tables**, **Hash Sets**, and **Hash Maps** using Python. Perform operations such as insertion, searching, updating, deletion, collision handling using chaining and linear probing, and hashing using a simple hash function.

Develop a **Train Reservation System** where passengers can:

- Reserve a train seat.
- Cancel an existing reservation.
- Search passenger records using Passenger ID.
- Automatically add passengers to a waiting list when all seats are occupied.
- Automatically assign an available seat to the first passenger in the waiting list after a cancellation.
- Prevent duplicate reservations using unique Passenger IDs.

---

## DSA Topics Covered

- Hash Tables
- Hash Maps (Python Dictionary)
- Hash Sets (Python Set)
- Hash Functions
- Collision Handling (Chaining)
- Collision Handling (Linear Probing)
